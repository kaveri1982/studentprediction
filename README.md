# Student Performance Prediction

## Project Overview

A Machine Learning web application that predicts a student's final score
using Linear Regression.

### Technologies Used

-   Python
-   Flask
-   HTML & CSS
-   Scikit-learn
-   Pandas
-   Joblib

### Project Structure

studentprediction/ - app.py - dataset.csv - student_model.pkl -
templates/ - index.html - result.html - static/

### How to Run

1.  Open the project folder.
2.  Run `python app.py`
3.  Open `http://127.0.0.1:5000`
